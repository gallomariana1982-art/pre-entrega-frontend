🛠️ ¿Qué le agregué al sitio? (Consignas cumplidas)

1. Estructura HTML5 bien semántica

Armé toda la estructura usando etiquetas semánticas para que todo quede súper ordenado y accesible: <header>, <nav>, <main>, <section>, <article> y <footer>. También sumé un menú con hipervínculos internos para navegar fácil entre las secciones.

2. Formulario de contacto funcional con Formspree

Creé el formulario de contacto para que me puedan escribir directamente. Lo conecté con Formspree usando el método POST, así que los mensajes que mandan desde la página me llegan directo al mail.

Campos incluidos: Nombre completo, Correo electrónico y Mensaje.

3. Estilos y Google Fonts

Vinchulé todo desde un archivo externo (styles.css).

Tipografías: Usé Poppins para los títulos y Roboto para el texto del cuerpo desde Google Fonts.

Fondos: Le puse un degradado copado (linear-gradient) a la sección principal para darle más onda.

4. Diseño Responsivo (Flexbox + CSS Grid + Media Queries)

Productos: Usé Flexbox para acomodar las tarjetas de los cursos para que se ajusten solas según el espacio.

Reseñas: Armé una cuadrícula responsiva usando CSS Grid para mostrar las opiniones de los estudiantes.

Mobile First / Media Queries: Sumé @media queries para que la página se adapte sin problemas a pantallas de celulares y tablets (se acomodan las tarjetas, la tabla y el menú de navegación).

5. Contenido Multimedia

Agregué un reproductor de video nativo de HTML5 con sus respectivos subtítulos .vtt y también un reproductor incrustado vía <iframe> desde YouTube.
